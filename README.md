# Base de apps (offline + Google)

Modelo para criar apps pessoais **instaláveis**, que **funcionam sem internet** e sincronizam com uma
**planilha do Google** — com visual pronto para **tablet, celular e/ou PC**.

- **Como usar:** [COMO-USAR.md](COMO-USAR.md) ← comece por aqui
- **Visual e componentes:** [DESIGN.md](DESIGN.md)
- **Como funciona por dentro:** [ARQUITETURA.md](ARQUITETURA.md)
- **Instruções para o Claude:** [CLAUDE.md](CLAUDE.md)

Criar um projeto novo:

```powershell
powershell -ExecutionPolicy Bypass -File D:\03-PESSOAL\_BASE-APP\criar-projeto.ps1
```

Origem: extraída do app **Agenda** (github.com/Iristenio/agenda).
